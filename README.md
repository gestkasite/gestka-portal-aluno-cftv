# GESTKA — Portal do Aluno CFTV

Site estático responsivo, pronto para publicação no GitHub Pages.

## Arquivos incluídos

- `index.html` — página principal do portal.
- `css/style.css` — identidade visual, layout responsivo e estilos.
- `js/app.js` — menu mobile, ano automático e checklist interativo.
- `assets/` — logotipo e ilustrações SVG locais para que as imagens acompanhem o site.

## Como publicar no GitHub Pages

1. Descompacte o arquivo ZIP no computador.
2. Abra o repositório `gestkasite/gestka-portal-aluno-cftv` no GitHub.
3. Selecione **Add file → Upload files**.
4. Envie o conteúdo desta pasta, incluindo `index.html`, `css`, `js` e `assets` (envie os arquivos/pastas, não apenas o ZIP).
5. Confirme em **Commit changes**.
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, selecione **Deploy from a branch**.
8. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
9. Aguarde a publicação e teste: `https://gestkasite.github.io/gestka-portal-aluno-cftv/`

## Personalização

- WhatsApp de suporte: altere o link `wa.me` no `index.html`.
- Simulador externo: altere o link `cctv-simulator.com` se necessário.
- Identidade visual: ajuste as cores no início de `css/style.css`.

## Observações

O simulador é externo. O painel ilustrado no portal é apenas uma imagem decorativa, não uma transmissão de câmeras. O checklist funciona no navegador e não salva respostas em servidor.
